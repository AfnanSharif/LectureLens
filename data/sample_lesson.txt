Linear regression is a supervised learning method that models the relationship between input features and a continuous target. The model predicts a value by multiplying each feature by a learned coefficient and adding an intercept. A coefficient describes the expected change in the prediction when its feature increases by one unit while other features stay fixed. Training commonly minimizes mean squared error, which penalizes larger residuals more strongly because each error is squared. A residual is the difference between an observed value and the model prediction. Gradient descent can minimize the loss iteratively, while the normal equation provides a direct solution for smaller well-conditioned datasets. Before training, analysts inspect missing values, unusual observations, and feature scales. A train-test split keeps evaluation examples separate from examples used to fit coefficients. Root mean squared error expresses typical prediction error in the same unit as the target. The coefficient of determination, called R squared, measures the fraction of target variance explained by the model. A high training score alongside a weak test score can indicate overfitting. Linear regression assumes a linear relationship, independent errors, roughly constant residual variance, and limited multicollinearity. A residual plot helps reveal curved patterns or changing variance that violate these assumptions. Regularization can improve generalization when features are numerous or correlated. Ridge regression adds a squared-coefficient penalty, while lasso regression can shrink some coefficients to zero. The central workflow is to inspect data, define a defensible split, fit the pipeline, evaluate on unseen data, and diagnose residuals before trusting predictions.
